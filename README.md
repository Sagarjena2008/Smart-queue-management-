# SmartQueue

SmartQueue is a local queue-management website built with Python, SQLite, HTML, CSS, and JavaScript. Tokens are stored in `smartqueue.db` on this computer; no online service or account is used.

## Run on Windows

1. Install Python 3 from [python.org](https://www.python.org/downloads/) and enable **Add Python to PATH** during installation.
2. Double-click `run.bat`. It opens the website at <http://127.0.0.1:8000>.
3. Keep the command window open while using the website. Press Ctrl+C in that window to stop the server.

The app uses only Python's standard library. The customer token form, live queue, token lookup, staff status controls, and CSV export are available locally.
